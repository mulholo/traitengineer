# Architecture decision records

One file per decision: `NNNN-title.md` with context, decision and alternatives. 0001–0019 cover the stack
table in the v1 spec (section 2); later numbers are decisions made during the build. Any dependency not named in
the spec needs an ADR. To supersede a decision, add a new ADR and set the old one's status to
`superseded by NNNN`.
