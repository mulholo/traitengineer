# 0012. Expo for mobile and web

- Status: accepted
- Date: 2026-10-14

## Context

One codebase for iOS (primary), Android and web.

## Decision

Expo (latest SDK) with Expo Router, TanStack Query (persisted queries/mutations), NativeWind, React Hook Form + Zod resolver, and expo-notifications/secure-store/quick-actions/haptics.

## Alternatives considered

Separate native + web apps (double the work); Flutter (not TypeScript).
